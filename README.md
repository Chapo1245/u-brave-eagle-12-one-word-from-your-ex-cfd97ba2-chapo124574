Entrants send exactly one word their ex would use to describe them. The funniest, most painfully honest word takes the whole reward.

This entry's word is **almost** — the one word an ex would use for someone who was never quite the one, never quite enough, never quite stayed. It stings because it is true, and it needs no explanation.

## Why this word

Three candidates were judged against each other and against the obvious clichés for this topic ("toxic", "selfish", "cheater", "immature"):

- **almost** — the surprise is the angle: not an insult, a measurement. It lands instantly, it is painfully honest, and no near-synonym keeps its edge.
- **placeholder** — clever, but it needs a beat to land and it describes a role, not a person.
- **draft** — funny, but a writer's metaphor; narrower and less universal than "almost".

"Almost" won: biggest laugh gap, tightest sting, smallest text (6 bytes), and the most relatable — everyone has been someone's almost.

## Run it

```sh
python3 main.py
```

The program writes the single word to `/output/entry.txt`, deterministically, using only the Python standard library.
